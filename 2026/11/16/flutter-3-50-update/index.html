출처: What’s new in Flutter 3.50 (The Flutter Blog, 2026-11-11)

Flutter 3.50이 Dart 3.14와 함께 나왔다. 네이티브 API 직접 호출이 정식이 됐고, iOS 터치 지연이 한 프레임 줄었다. Android 릴리스 빌드는 외부 Intent로 엔진을 조작하지 못하게 막았고, 웹은 Safari·Firefox에서도 WebAssembly로 빨라졌다. 새 프로젝트는 SDK에서 분리된 Material·Cupertino 패키지를 기본으로 쓴다. CocoaPods와 Intel Mac 지원은 정리 단계에 들어갔다.

네이티브 직접 호출 정식

플랫폼 채널은 메시지를 직렬화해 주고받고, 채널과 메서드를 문자열 이름으로 연결하며, 호출이 무조건 비동기다. 3.50부터는 이 단계를 거치지 않고 Dart와 네이티브 코드가 서로를 바로 호출할 수 있다. 동기 호출도 되고, 백그라운드 isolate에서도 호출할 수 있다.

  • FFIgen(C, Objective-C)과 JNIgen(Java, Kotlin)이 정식이 됐다.
  • 여러 플랫폼을 지원하는 플러그인용으로 Pigeon의 native interop 모드가 미리보기로 나왔다. iOS·macOS·Android에서 데이터 변환과 네이티브 객체 수명을 알아서 처리한다.
  • 자세한 내용은 Native interop 문서에 있다. 따로 소개 글도 낼 예정이라고 한다.

iOS·macOS

Xcode 27과 iOS 27이 출시된 뒤 처음 나온 정식 버전이다.

  • 터치 지연 1프레임 단축: 터치 이벤트를 바로 프레임워크에 넘겨 같은 화면 갱신 안에 프레임을 만든다. 60Hz 기기에서 16ms, 120Hz ProMotion 기기에서 8ms 빨라졌다. iPhone 6s(2015)까지 벤치마크로 확인했고, 지연을 더 줄이는 작업이 진행 중이라고 한다.
  • 디버깅 개선: 새로 연결했거나 업데이트한 iPhone에서는 Xcode를 한 번 열기 전까지 앱이 흰 화면에서 멈췄는데, 이제 CLI가 기기를 자동으로 준비한다. iOS 27 기기에서 flutter run이 가끔 크래시 나던 문제도 고쳤다. Xcode 27로 빌드하면 실기기에서 flutter screenshot이 iOS 17 이후 처음으로 다시 동작한다.
  • Swift Package Manager 전환: CocoaPods trunk가 2026년 12월에 읽기 전용이 된다. 3.50부터는 SPM을 끄면 모든 CLI 명령에서 경고가 뜨고, 앞으로는 SPM을 끄는 옵션과 CocoaPods 대체 경로 자체를 없앤다. 빌드 문제 때문에 SPM을 꺼 뒀다면 지금 다시 켜서 확인하라고 권한다.
  • Intel Mac 지원 종료 예고: 더는 Intel Mac에서 테스트하지 않고, Intel Mac에서 빌드하면 경고가 한 번 뜬다. 지원이 종료되면 iOS·macOS·Android 빌드 모두 Apple Silicon Mac이 필요하다. Apple Silicon 전용 macOS 앱은 지금도 flutter config --enable-macos-arm64-only로 만들 수 있다.

Android

  • Intent 보안 강화: 지금까지는 기기에 설치된 다른 앱이 Intent extra로 실행 설정을 넘길 수 있었다. 이제 릴리스 빌드는 외부 Intent extra의 route, dart_entrypoint, cached_engine_id 값과 엔진 플래그를 무시한다. 일반적인 딥링크는 그대로 동작한다.
  • Hybrid Composition++: 지도나 웹뷰 같은 네이티브 뷰를 넣을 때 쓰는 새 플랫폼 뷰 방식이 더 나아졌다. Android 14(API 34) 이상과 Vulkan이 필요하고, 조건이 안 맞으면 기존 방식으로 자동 전환된다. 정식 버전의 기본값은 아직 아니다.
  • Built-in Kotlin 전환: Android 코드가 있는 플러그인은 Android Gradle Plugin(AGP)의 Built-in Kotlin으로 옮겨야 한다. Kotlin Gradle Plugin을 직접 적용하는 플러그인은 앞으로 pub.dev 점수가 깎이고 AGP 10에서는 빌드가 실패한다.
  • 새 프로젝트 기본값: AGP 9.3.1, Gradle 9.5.0, compile·target SDK 36, min SDK 24.

Material·Cupertino 분리

SDK에 묶여 있던 package:flutter/material.dart, cupertino.dart와 flutter_localizations의 해당 delegate가 deprecated 됐다. 3.47에서 1.0이 나온 별도 패키지 material_ui, cupertino_ui로 옮겨 가는 과정이다. flutter create로 만든 새 프로젝트는 처음부터 package:material_ui를 쓴다.

기존 프로젝트는 다음 명령으로 import와 delegate를 자동으로 바꿀 수 있다. 자세한 내용은 마이그레이션 가이드에 있다.

dart fix --apply --code=migrate_design_widgets

웹

  • flutter build web --wasm으로 빌드하면 Safari 26.2+(macOS·iOS)와 Firefox 147+에서 무거운 위젯 벤치마크 기준 프레임레이트가 JavaScript의 2배를 넘는다. 이 두 브라우저에서는 Wasm이 아직 기본으로 켜져 있지 않아 flutter_bootstrap.js의 wasmAllowList로 직접 켜야 한다. Chrome·Edge 137+에서는 이미 기본으로 켜져 있다.
  • --web-content-hash를 주면 빌드 파일 이름에 해시가 붙어, 배포 뒤 사용자 브라우저에 옛 파일이 캐시로 남는 문제가 없어진다.
  • dart:html, dart:js 같은 옛 JS interop 라이브러리가 deprecated 됐다. --no-deprecated-js-interop를 주면 아직 옛 라이브러리에 의존하는 곳을 빌드 단계에서 찾아 준다.
  • 미리보기로 나온 WebParagraph는 글자 배치를 브라우저에 맡긴다. CanvasKit 다운로드가 5.46MB에서 약 3.75MB로 줄고, 대체 폰트를 따로 받지 않아도 되며, 글자가 네모 상자로 깨지는 문제도 없어진다.

AI 도구

  • 공식 Flutter 에이전트 플러그인이 나왔다. 에이전트 skill, Dart·Flutter MCP 서버 설정이 들어 있고, lib/ 아래 파일을 고치면 MCP로 hot reload를 거는 규칙(flutter-hot-reload)도 있다.
  • 패키지 작성자는 pub.dev 패키지의 skills/ 폴더에 에이전트 skill을 넣어 배포할 수 있다. 앱 개발자는 의존하는 패키지에 들어 있는 skill을 찾아 설치할 수 있다.

그 밖에 Genkit Dart 1.0과 Google AI Edge의 온디바이스 MediaPipe 패키지가 나왔고, Google Play에 올라간 Flutter 앱이 100만 개를 넘었다. 위젯과 엔진의 세부 변경은 원문과 breaking changes에 있다.

업그레이드 전 확인할 것

  • iOS: SPM을 꺼 뒀다면 다시 켜고 빌드되는지 확인한다(CocoaPods trunk는 2026년 12월에 읽기 전용).
  • Android: 직접 만든 플러그인이 Kotlin Gradle Plugin을 수동으로 적용하고 있다면 Built-in Kotlin으로 옮긴다.
  • Android: 릴리스 빌드에서 다른 앱이 보낸 Intent extra로 화면(route)을 정하고 있었다면 더는 동작하지 않는다.
  • 공통: dart fix --apply --code=migrate_design_widgets로 Material·Cupertino import를 옮긴다.
  • 빌드 환경: Intel Mac에서 빌드하고 있다면 Apple Silicon Mac으로 옮길 준비를 한다.
